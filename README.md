\# Hospital Appointment System



\## About the Project

A simple Hospital Appointment System developed using Python and SQLite.



\## Features

\- Patient Registration

\- Patient Login

\- Doctor List

\- Doctor Specialization

\- Available Appointment Slots

\- Book Appointment

\- Cancel Appointment

\- Check Appointment Status



\## Technologies Used

\- Python

\- SQLite

\- HTML

\- CSS

\- JavaScript



\## Project Structure

\- app.py

\- hospital.db

\- templates/

\- static/

\- README.md



\## How to Run

1\. Open the project folder.

2\. Open Command Prompt in the project folder.

3\. Run:

&#x20;  python app.py

4\. Open the application in a web browser.
